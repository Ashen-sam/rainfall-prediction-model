# Rainfall Prediction Model

AI model developed to **predict rainfall** using historical weather data. Built for a Kaggle competition to forecast precipitation accurately. Implemented using **Python** and modern machine learning techniques.

---

## Project Overview

This project focuses on forecasting rainfall using historical weather patterns. Multiple machine learning algorithms were employed to improve prediction accuracy.

- **Goal:** Predict rainfall with high precision using historical weather data.  
- **Approach:** Data preprocessing, feature engineering, model training, and evaluation.  
- **Environment:** Developed entirely in **Google Colab**.

## Models Used

- **XGBoost:** Gradient boosting decision trees for high accuracy.  
- **LightGBM:** Efficient gradient boosting framework for large datasets.  
- **Decision Tree:** Interpretable tree-based model.  
- **Neural Network:** Deep learning approach for complex patterns in data.
